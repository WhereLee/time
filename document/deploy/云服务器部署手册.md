# 云服务器部署手册（P6 收口 · reason-main + reason-device-sim）

> 服务器：124.223.36.154 / ubuntu（sudo 免密）/ Ubuntu 24.04 / Java 17.0.19 已装 / MySQL 8.x + Redis 已装（清场态 disabled）
> 部署形态：systemd 双服务 + 外部化配置（/opt/reason/config/）+ Jasypt 密码加密

## 目录约定

```
/opt/reason/
├── main/    reason-main-1.0.0.jar
├── sim/     reason-device-sim.jar
├── logs/    （两服务日志软链或各自 logs/ 相对目录）
└── config/
    ├── application-prod.yml      # 外部化 prod 配置（spring.datasource/reason.device 覆盖），600
    ├── reason-main.env           # systemd EnvironmentFile（JASYPT_ENCRYPTOR_PASSWORD），600
    └── reason-sim.env            # 同上（sim 无 jasypt 需要，可留空/注释）
```

## 步骤

1. **启用中间件**：`sudo systemctl enable --now mysql redis-server`
2. **建库与账号**（root 本地 socket 登录）：
   - `CREATE DATABASE reason_faster DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_general_ci;`
   - 建业务账号 `reason_app`@`localhost`（随机强密码）授权 reason_faster 全库
3. **导入基线**：`mysql -uroot reason_faster < db/reason-faster.sql` → `02-parking.sql` → `03-系统管理员授权停车菜单.sql`（文件名序 = 依赖序；03 幂等）
4. **生成 Jasypt 密文**（本地，密钥自定）：
   ```
   java -cp ~/.m2/repository/org/jasypt/jasypt/1.9.3/jasypt-1.9.3.jar \
     org.jasypt.intf.cli.JasyptPBEStringEncryptionCLI \
     input=<reason_app 密码> password=<JASYPT_ENCRYPTOR_PASSWORD> \
     algorithm=PBEWITHHMACSHA512ANDAES_256 ivGeneratorClassName=org.jasypt.iv.RandomIvGenerator
   ```
   输出 ENC(密文) 填入外部化 yml；密钥写入 reason-main.env（chmod 600）
5. **外部化配置** `/opt/reason/config/application-prod.yml`（内容 = 仓库 application-prod.yml 模板 + 覆盖 spring.datasource.username/password=ENC(...) + reason.device.access-token 独立值）
6. **部署 jar**：scp 双 jar 到 /opt/reason/{main,sim}；unit 文件拷 /etc/systemd/system/；`sudo systemctl daemon-reload`
7. **启动**：`sudo systemctl enable --now reason-main reason-device-sim`；健康检查 `curl http://127.0.0.1:8200/api/actuator/health`
8. **防火墙**：`sudo ufw allow 8200/tcp`（8300 仅本机回环不开放）

## M0 云上验收清单（7 条）

| # | 验收 | 跑法 |
|---|---|---|
| 1 | 管理端权限闭环 | 登录 adminManager（服务器库种子密码 admin123 → **部署后立即改强密码**）→ 车位 save/禁用/占用中拒绝 |
| 2 | 设备双进程链路 | sim `/sim/event/DEV-001/entry` → main 会话 → exit → 订单 + sim 日志 OPEN_GATE |
| 3 | 并发入场唯一 | 双线程并发打 `/device/parking/entry` 同车位 → 仅一成功 |
| 4 | 取消语义 | cancel → 会话 state=2 + 车位释放 |
| 5 | 计费正确 | DB 回拨 entry_time 65 分钟 → exit → 金额 400 分断言 |
| 6 | 可观测性 | traceId 响应头+日志、health/info、慢 SQL 日志 |
| 7 | 重启恢复 | systemctl restart reason-main → 数据仍在服务自愈 |

## 安全清单

- 服务器 MySQL/Redis 仅监听 127.0.0.1（检查 bind-address；Redis 无密码默认——ufw 未开 6379 即外部不可达，仍建议 requirepass）
- adminManager 首登改强密码（登录接口 password 字段新密码）
- /opt/reason/config/ 目录 700，yml/env 600
- device access-token 用 prod 独立值（本地 dev 值不同）
- 8300 不对公网开放（sim-base-url 127.0.0.1）
