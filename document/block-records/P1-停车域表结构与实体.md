## 交付清单

   - `park_space`（车位台账：编号唯一索引 u_space_no，无物理删除）
   - `park_session`（会话状态机：三个时间位 entry/exit/cancel 对应三条迁移路径；idx_space_state(space_id, session_state) 服务入场查重兜底查询）
   - `fee_rule`（计费规则：单价分/小时 + rule_state 启停；预置默认规则 rule_id=1 单价 200 分）
   - `park_order`（结算快照：车牌/车位/时间/单价全部冗余；amount_fen BIGINT；u_order_session 唯一索引防并发双订单）
   - sys_menu 菜单注册 9 行（menu_id 200-208，INSERT IGNORE 幂等）
2. **实体 ×4 + Dao ×4**（`modules/parking/entity|dao`，对齐壳子 @Schema/@TableName/@TableId/BaseMapper 风格）
3. **AuthIT 挂载 02-parking.sql**：CI 从零建库时按文件名序执行（01 基线 → 02 业务域）

## 关键设计决策（P1 讨论拍板）

| 决策 | 内容 | 理由 |
|---|---|---|
| DDL 文件形态 | 01 壳子基线冻结 + 02-parking 域文件（未来 03-charging），AuthIT 顺序挂载 | 边界先行；initdb 按文件名序执行；Navicat 全量导出另存约定 |
| 无物理删除 | 车位删除=禁用（space_state=2）；会话/订单只增不改 | 历史引用悬空问题；壳子 @TableLogic 半吊子状态不学 |
| 时间字段 | bigint(20) 秒级 epoch（三个时间位 + updatetime） | 壳子全库零 datetime 列，统一风格 |
| 订单快照 | plate_no/space_no/entry/exit/unit_price_fen 全冗余 | 规则调价/车位复用后历史订单不漂移 |
| 金额分存储 | amount_fen BIGINT、unit_price_fen INT（分） | A/B/C 拍板项落地 |
| 状态列 | tinyint + 注释语义（会话 0/1/2、车位 0/1/2、规则 0/1、订单 0） | Java 侧枚举与状态机归 P2 |
| 无「进行中会话」唯一索引 | 条件更新 + 应用层查重兜底（idx_space_state 支撑） | MySQL 8 无 partial index，条件更新本身原子 |
