# 升降杆样例——运行与演示手册

一个"十公里外的杆"的完整控制闭环：平台（reason-main）+ 设备模拟器（reason-barrier-sim）双进程，覆盖台账、指令、事件、心跳、自动规则、超时对账、故障告警、防砸互锁全部机制。

## 环境要求

- JDK 17、Maven、MySQL（reason_faster 库）、Redis（**db15**，框架配置）
- 依次导入 `db/reason-faster.sql`（框架基线）→ `db/02-barrier-device-record.sql`（台账+菜单）→ `db/03-barrier-full-loop.sql`（流水/告警表+Quartz 任务注册+权限）

## 启动（顺序：平台 → 模拟器）

```powershell
# 1. 平台（8200，context-path=/api）
cd inteink-faster\reason-main; mvn spring-boot:run

# 2. 模拟器（8300，仅绑 127.0.0.1）
cd inteink-faster\reason-barrier-sim; mvn spring-boot:run
```

启动即自动发生：模拟器**上电自述**（心跳通道校正平台台账）→ 平台 Quartz 加载 job 200/201 → `barrierAutoTask` 每分钟对账（白天窗口 08:00-18:00 内自动升杆）→ `barrierMonitorTask` 每 30s 超时/离线扫描。

登录：`POST /api/sys/login {"loginname":"adminManager","password":"admin123"}`，后续请求带 header `token`。

## 演示剧本（每个边界怎么触发）

| 演示 | 操作 | 观察点 |
|------|------|--------|
| 自动升降 | 什么都不做，等整分 | main 日志 `自动对账发现偏差 ... 下发校正指令 OPEN`；台账 state 变化 |
| 手动闭环 | `POST /api/device/command/open {"deviceNo":"BARRIER-E-01"}` | 3s 内 state 2→3→1；流水 PENDING→ARRIVED |
| 防连点 | 1 秒内连发两次 open | 第二次 `操作过于频繁`（@RepeatGuard） |
| 手动保持期 | 手动指令后看 Redis | `barrier:manual-hold:{no}`=userId TTL 30min；期间 autoTask 日志 `让位` |
| 防砸互锁 | `POST :8300/sim/vehicle {"deviceNo":"...","present":true}` → 平台 close | close 被拒 `杆下有车`；流水 SEND_FAILED |
| 卡杆故障 | `POST :8300/sim/fault` → 平台 open | state→4(FAULT)；告警 type=4；流水 EXEC_FAILED；再发指令被拒 `故障中` |
| 人工复位 | `POST :8300/sim/recover` | state→2；DOWN 事件上报 |
| 外力改态 | `POST :8300/sim/tamper {"state":"UP"}` | 台账被设备自述校正（非指令驱动） |
| 断电恢复 | 直接重启 sim 进程 | 上电自述→平台 `心跳对账发现状态漂移` 校正+告警 |
| 离线判定 | 停 sim 等 35s | 台账 online=false；告警 type=2；Redis online key 过期 |
| 事件丢失+重试幂等 | sim yml `event-url` 改错地址重启 + 平台 `command-timeout-seconds: 10`、`max-retry: 1` 重启 | 心跳兜底校正台账；monitor `经台账对账确认已到位，销账`（若台账未到位则重试同 seq→超限告警） |
| 设备侧快照 | `GET :8300/sim/status` | 物理真相（state/faultInjected/vehiclePresent）vs 平台台账快照 |

## 接口清单

**管理端**（token + 权限）：
- `GET /api/device/record/list`（device:record:list，含 online 实时字段）
- `POST /api/device/record/save`（device:record:save）
- `POST /api/device/command/open|close`（device:command:open|close，@RepeatGuard+@ManualHold+@SysLog）
- `GET /api/device/alarm/list`（device:alarm:list）
- `GET /api/device/commandlog/list`（device:commandlog:list）

**设备通道**（X-Device-Token: barrier-sim-token-2026，白名单免登录）：
- `POST /api/device/event` {deviceNo, state}——状态事件（台账唯一合法写入口）
- `POST /api/device/heartbeat` {deviceNo, state}——心跳（TTL 续命+对账）

**模拟器**（仅 127.0.0.1）：
- `POST /cmd` {deviceNo, action, commandSeq}——平台指令入口（code=0 受理/幂等忽略，code=1 拒绝）
- `POST /sim/fault|recover|tamper|vehicle`、`GET /sim/status`——物理世界注入口

## 配置速查

平台 `reason.barrier.*`：auto-enabled / auto-open-time / auto-close-time（支持跨午夜）/ heartbeat-timeout-seconds=30 / command-timeout-seconds=60 / max-retry=3 / manual-hold-minutes=30 / reconcile-grace-seconds=3 / alarm-dedup-seconds=300

模拟器 `sim.*`：event-url / heartbeat-url / heartbeat-interval-seconds=10（须小于平台超时阈值）/ token / move-millis=3000 / devices[]（deviceNo 须与平台台账登记对齐）

## 状态与类型码

- 设备状态：0-未接入 1-升起 2-降下 3-动作中 4-故障（台账状态**只信设备上报**，指令侧/任务侧禁改）
- 指令流水：0-待到位 1-已到位 2-下发失败 3-重试超限 4-执行失败(设备故障)；触发源：1-手动 2-自动规则 3-超时重试
- 告警类型：1-重试超限 2-离线 3-对账不一致 4-设备故障
